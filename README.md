### What I build

- Deployed a 7-stage agentic RAG system on AWS ECS Fargate with LangGraph orchestration, pgvector semantic search, and a deterministic trade policy engine — production CI/CD via GitHub Actions
- Fine-tuned Bio_ClinicalBERT on 326,517 clinical sentences achieving **94.99% recall** for PHI detection, with a real-time HIPAA governance layer over LLM outputs
- Built end-to-end MLOps pipelines processing millions of records through automated feature ingestion, hourly live inference, and weekly MLflow model retraining — fully orchestrated with GitHub Actions
